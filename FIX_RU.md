# Исправление отправки Meta Pixel

Для сайта https://prostudy.com.ua/ и пикселя 2295810454598491.

## Что исправлено

На работающем сайте код пикселя загружался, но браузер блокировал отправку события из-за Content Security Policy: не были разрешены отправка формы и загрузка фрейма с адреса Meta. В server.py добавлены разрешения `form-action` и `frame-src` для https://www.facebook.com.

## Как установить

1. Распакуйте архив.
2. Загрузите `server.py` в корень репозитория https://github.com/atmosferafyndrac-eng/prostudy через Add file → Upload files и сохраните изменения.
3. Обновите и перезапустите сайт на хостинге. Если используете Docker Compose, выполните в папке проекта на сервере:

   ```sh
   git pull
   docker compose up -d --build
   ```

Если обновляете сайт вручную, замените `server.py` в папке проекта на сервере и перезапустите приложение.

После обновления откройте тестирование событий для пикселя 2295810454598491 в Meta Events Manager и посетите главную страницу сайта без блокировщика рекламы. Проверьте появление PageView.

## Проверка исправления

В тестовой версии с исправленной политикой браузер отправил PageView для пикселя 2295810454598491. Адрес Meta /tr/ вернул HTTP 200, ошибок блокировки политикой безопасности не было. Появление события в кабинете Meta отдельно не проверялось.

Исправление подготовлено локально. На работающий сайт его ещё нужно установить.
