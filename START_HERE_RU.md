# Как запустить сайт danil.prostudy

Сайт уже содержит внешний вид, форму заказа, базу SQLite, админ-панель и код Telegram-уведомлений. **Это готовый проект, но ещё не опубликованный в интернете сайт.** Для публичного запуска нужны домен или адрес хостинга и настройка секретов.

## 1. Посмотреть на своём компьютере

1. Установите Python 3.10 или новее с python.org (для Windows включите «Add Python to PATH»).
2. Распакуйте ZIP и переименуйте `.env.example` в `.env` (или просто скопируйте с таким названием).
3. Откройте `.env` и напишите свой длинный пароль в `ADMIN_PASSWORD=...`.
4. Запустите `start_windows.bat` (Windows) или `python3 server.py` (macOS/Linux).
5. Откройте в браузере `http://localhost:8080`. Заявки и их статусы — `http://localhost:8080/admin`.

Пример: если заполните `ADMIN_PASSWORD=MyLongUniquePassword2026!`, в кабинет нужно входить с этим же паролем. **Замените пример на свой уникальный пароль.**

## Как клиент оставляет контакт

В форме клиент выбирает **Telegram, Viber или WhatsApp**. Для Telegram оставляет `@username`, для Viber/WhatsApp — номер с международным кодом (например, `+380 99 123 45 67`). Мессенджер и контакт сохраняются в заявке, видны в админке и уведомлении менеджеру. После обновления проекта существующая база автоматически дополняется новым полем, старые заказы не удаляются.

## 2. Получать заказы в Telegram

- Создайте собственного Telegram-бота через `@BotFather` → `/newbot`.
- Напишите боту /start либо добавьте его в приватную группу для заказов.
- Получите `TELEGRAM_CHAT_ID`: после сообщения используйте Telegram Bot API `getUpdates`, посмотрите `message.chat.id` (для групп часто начинается с `-100`).
- Введите `TELEGRAM_BOT_TOKEN=...` и `TELEGRAM_CHAT_ID=...` в `.env`, перезапустите сайт.
- Отправьте тестовую заявку, проверьте Telegram. Если сообщение не придёт, заявка всё равно будет в кабинете.

Не пересылайте токен бота посторонним и не публикуйте его. Если хотите получать заявки на email, параметры SMTP описаны в README.md.

## 3. Опубликовать сайт в интернете

Для настоящего запуска рекомендую VPS + Docker + Caddy (автоматический HTTPS) и ваш домен. Настройка по шагам описана в README.md. Не используйте бесплатный хостинг с непостоянным диском для базы заявок: они могут исчезнуть после перезапуска. Перед публикацией добавьте юридические контакты и проверьте `/privacy`.

## Что можно настроить потом

Можно заменить название, тексты, услуги и контакты, добавить прикрепление методичек, онлайн-оплату, отдельные страницы услуг, SEO и аналитику. Сейчас цены специально не придуманы — клиент запрашивает индивидуальный расчёт.
