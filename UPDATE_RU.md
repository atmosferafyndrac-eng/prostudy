# Обновление Meta Pixel для prostudy

Пиксель: **2295810454598491**. Событие: **PageView** при открытии главной страницы.

## Установка через GitHub

1. Распакуйте `prostudy-meta-pixel-update.zip`.
2. В репозитории https://github.com/atmosferafyndrac-eng/prostudy откройте **Add file → Upload files**.
3. Загрузите в корень репозитория четыре файла: `index.html`, `meta-pixel.js`, `server.py`, `Dockerfile`. Сохраните изменения кнопкой **Commit changes**.
4. Обновите сайт из репозитория через ваш хостинг. Если сайт запущен через Docker Compose на сервере, в папке проекта выполните:

   ```sh
   git pull
   docker compose up -d --build
   ```

Если вы переносите файлы на сервер вручную, замените `server.py` и `Dockerfile` в папке проекта, а `index.html` и `meta-pixel.js` разместите в папке `static/`. Затем перезапустите сервер. При сборке через Docker размещение файлов выполнит Dockerfile.

## Проверка после установки

В Meta Events Manager выберите пиксель **2295810454598491**, откройте тестирование событий и посетите главную страницу вашего сайта. Проверьте получение **PageView**. Для проверки используйте браузер без блокировщика рекламы.

## Что изменено

- `index.html`: подключение пикселя и резервное изображение для браузеров без JavaScript.
- `meta-pixel.js`: ваш код Meta, вынесенный в отдельный файл для совместимости с настройками безопасности сайта.
- `server.py`: разрешены необходимые адреса Meta в политике безопасности.
- `Dockerfile`: новый файл пикселя включён в сборку.

Локально проверены очередь инициализации и PageView, выдача файлов сервером, настройки безопасности и состав файлов для Docker. Все 12 существующих тестов проекта прошли. Получение события в Meta проверяется после публикации на вашем сайте.

Архив подготовлен на основе коммита `7933210` ветки `main`. Изменения пока не загружены в GitHub и не опубликованы на работающем сайте.
