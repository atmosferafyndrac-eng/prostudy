# Google Tag Manager GTM-N2R29CGH

Обновление для https://prostudy.com.ua/ на основе версии репозитория eaf0cb7.

## Установка

1. Распакуйте `prostudy-google-tag-update.zip`.
2. В репозитории https://github.com/atmosferafyndrac-eng/prostudy через Add file → Upload files замените три файла в корне: `index.html`, `privacy.html`, `server.py`. Сохраните изменения.
3. Обновите сайт на хостинге. При использовании Docker Compose выполните в папке проекта на сервере:

   ```sh
   git pull
   docker compose up -d --build
   ```

При ручной установке замените `server.py` в папке проекта, а `index.html` и `privacy.html` — в папке `static/`. Перезапустите приложение.

## Что добавлено

- Стандартное подключение контейнера GTM-N2R29CGH в начале head на главной странице и странице конфиденциальности.
- Резервный iframe сразу после начала body.
- Разрешения в Content Security Policy для GTM, стандартных адресов Google Analytics/Ads и режима предварительного просмотра. Выполнение фиксированного встроенного кода разрешено по SHA-256; общие разрешения unsafe-inline и unsafe-eval для скриптов не добавлялись.

Административные страницы не подключаются к аналитике. Имеющиеся Meta Pixel и обработка Lead сохранены.

## Что настроить в Google

На момент проверки опубликованный контейнер отдавал пустой список тегов. Установка контейнера на сайт сама по себе не подключает Google Analytics или конверсии Google Ads: нужный тег и его настройки следует добавить и опубликовать в Google Tag Manager. В предоставленном фрагменте не было идентификатора GA4 или Google Ads, поэтому они не подставлялись.

## Проверка

После обновления сайта откройте https://tagassistant.google.com/ и подключите https://prostudy.com.ua/. Проверьте обнаружение GTM-N2R29CGH. Когда настроите теги внутри контейнера, проверьте их срабатывание в режиме Preview и опубликуйте изменения.

Локально в браузере проверены обе публичные страницы: контейнер загружается ровно один раз, Google возвращает HTTP 200, события gtm.js, gtm.dom и gtm.load обработаны; ошибок Content Security Policy нет. Хеш кода проверен для обеих страниц. Все 12 существующих тестов проекта прошли.

Обновление подготовлено локально и ещё не опубликовано на работающем сайте.
