# danil.prostudy — сайт із заявками, CRM та сповіщеннями

Повністю адаптивний сайт українською в білому, чорному та фіолетовому стилі Instagram-сторінки. Включає послуги, FAQ, форму заявок, SQLite, приватний кабінет менеджера, CSV-експорт і сповіщення в Telegram та/або email. Сайт є самостійним дизайном, **не копією** diploms.com.ua.

## Швидкий запуск локально

Потрібен **Python 3.10+**; npm/pip і сторонні бібліотеки не потрібні.

```bash
cp .env.example .env
# Відредагуйте .env, заповніть ADMIN_PASSWORD
python server.py
```

Відкрийте http://localhost:8080/ . Кабінет менеджера — http://localhost:8080/admin, пароль із `.env`. Якщо `ADMIN_PASSWORD` порожній, вхід до адмінки вимкнено. Перевірка сервера — `/health`.

> Якщо запускаєте на Windows: скопіюйте `.env.example` у файл `.env` вручну, а сервер запустіть `py server.py`.

## Як надходять заявки

1. Клієнт обирає **Telegram, Viber або WhatsApp**, зазначає нікнейм Telegram або міжнародний номер телефону та заповнює форму. Обраний месенджер записується в замовлення й показується менеджеру. Під час оновлення існуюча база SQLite автоматично додає нове поле без втрати старих заявок.
2. Сервер перевіряє поля, дату і антиспам-поле. Форма показує повідомлення про використання контакту та посилання на політику конфіденційності без обов’язкової галочки.
3. Заявка **спочатку** записується до SQLite (`data/orders.sqlite3`).
4. Якщо налаштовано Telegram/email, сервер надсилає сповіщення. У разі проблеми з відправкою заявка **залишається в базі**, а у кабінеті видно статус `failed`.
5. Менеджер бачить заявки, шукає, фільтрує, змінює статус (`Нова`, `У роботі`, `Завершена`, `Скасована`), залишає приватні нотатки й може завантажити CSV.

Важливо: зараз відправлення повідомлень синхронне, тому за повільного Telegram відповідь форми може затриматися до 8 секунд. Це робочий варіант для невеликого проєкту. Для великого навантаження краще черга завдань і періодичні повторні спроби.

## Telegram-сповіщення (рекомендовано)

1. У Telegram відкрийте **@BotFather**, створіть бота командою `/newbot`, отримайте токен.
2. Створіть приватну групу для менеджерів, додайте в неї нового бота. Надішліть туди будь-яке повідомлення, або відкрийте чат із ботом і натисніть **Start** для особистих повідомлень.
3. Дізнайтеся `chat_id` (числовий, для груп часто починається з `-100`). Зручно запитати `https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates` після повідомлення; результат містить `message.chat.id`. Не передавайте токен нікому і не публікуйте URL із токеном.
4. Додайте до `.env`:
   ```ini
   TELEGRAM_BOT_TOKEN=123456789:your_private_token
   TELEGRAM_CHAT_ID=-1001234567890
   ```
5. Перезапустіть сайт і відправте тестову заявку. У кабінеті для неї має бути `telegram_status = sent`. Якщо група не отримує повідомлення, переконайтеся, що бот доданий і має право писати, а `chat_id` правильний.

**Не надсилайте токен у відкритий чат, GitHub чи скриншоти.** Встановіть його лише на своєму сервері або через менеджер секретів хостингу.

## Email-сповіщення (необов'язково)

Заповніть `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM`, `NOTIFY_EMAIL_TO`. Для SMTP 465 використовується SSL, для 587 — STARTTLS. Часто необхідний пароль застосунку, а не пароль вашої пошти.

## Розгортання на VPS з HTTPS

1. Придбайте домен і VPS, встановіть Docker + Docker Compose і Caddy.
2. Скопіюйте папку проєкту на VPS. Створіть `.env` на сервері і задайте **унікальний складний** `ADMIN_PASSWORD`, `PUBLIC_URL=https://your-domain.ua` та Telegram-параметри. Не публікуйте `.env`.
3. Запустіть `docker compose up -d --build`. Compose відкриває сайт лише для локального проксі `127.0.0.1:8080`, **не в інтернет напряму**.
4. Налаштуйте DNS свого домену, перепишіть `Caddyfile.example` зі своїм доменом і ввімкніть Caddy на портах 80/443. Caddy автоматично забезпечить HTTPS, якщо DNS і мережа налаштовані.
5. Перевірте `https://your-domain.ua/`, `/admin`, форму заявки та Telegram. Регулярно робіть резервну копію Docker volume `prostudy_data`.

SQLite зберігається у Docker volume `prostudy_data` та не губиться під час звичайного перевстановлення контейнера. **Не видаляйте volume**, якщо хочете зберегти заявки. На Python-хостингу з ephemeral filesystem SQLite може зникати: використовуйте постійне сховище або мігруйте на PostgreSQL.

## Налаштування бренду

- Головні тексти та назву `danil.prostudy` змінюйте у `static/index.html`.
- Кольори — у верхніх змінних `static/styles.css` (`--violet`, `--ink`, `--lav`).
- FAQ, послуги, пояснення — також у `static/index.html`.
- Правила конфіденційності — `static/privacy.html` **необхідно адаптувати під фактичного власника та додати контактні реквізити перед запуском**.
- Ціни навмисно не вигадані: форму створено для індивідуального розрахунку.
- Заявка не містить завантаження файлів: методичку й додатки краще запросити вже в особистому листуванні. За потреби можна додати захищене завантаження у наступній версії.

## Безпека та обмеження

- Параметризовані SQL-запити; перевірка полів; ліміт JSON; rate-limit на IP; антиспам-поле; базовий CSP; cookie адміністратора `HttpOnly`/`SameSite=Lax`, у HTTPS також `Secure`; токен CSRF на зміни статусу.
- Адміністративні запити не публічні, пароль не зберігається у коді, сесії мають 12-годинний термін дії. Налаштуйте HTTPS і обмежте доступ до VPS; робіть резервні копії.
- Rate-limit працює у пам'яті одного процесу та прив'язаний до IP проксі; для великого сайту використовуйте Redis/Caddy rate-limit або WAF.
- Дотримуйтесь політики збереження персональних даних, не надсилайте клієнтські дані в публічні Telegram-групи. Розмежовуйте менеджерські доступи.
- Зразок політики конфіденційності не є юридичною консультацією.

## Структура

```text
server.py                    Python webserver, API, SQLite, CRM, сповіщення
static/index.html           адаптивний головний екран
static/styles.css           стиль сайту
static/app.js               форма та інтерактивність
static/admin.html           панель менеджера
static/admin.js             логіка CRM
static/login.html           сторінка входу
static/privacy.html         приклад політики конфіденційності
.env.example                налаштування без секретів
Dockerfile/docker-compose   контейнер і том для бази
Caddyfile.example           HTTPS reverse proxy
```
