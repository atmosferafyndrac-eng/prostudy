# Стандартное размещение кода Meta Pixel

Для https://prostudy.com.ua/ и пикселя 2295810454598491. Основа репозитория: c03e3fb.

## Что сделать

1. Распакуйте `prostudy-meta-standard-install.zip`.
2. В репозитории https://github.com/atmosferafyndrac-eng/prostudy через Add file → Upload files замените `index.html` и `server.py` в корне. Сохраните изменения.
3. Обновите сайт на хостинге. При использовании Docker Compose выполните в папке проекта на сервере:

   ```sh
   git pull
   docker compose up -d --build
   ```

При ручном обновлении замените server.py в папке проекта и index.html в папке static/, затем перезапустите приложение.

4. Снова откройте настройку событий в Meta, укажите `https://prostudy.com.ua/` и нажмите «Добавить события».

## Что изменено

Базовый код Meta Pixel с инициализацией и PageView теперь расположен непосредственно внутри head главной страницы. Ранее он подключался отдельным отложенным файлом. Это убирает различие между исходным HTML и тем кодом, который выполняется после загрузки страницы, а также задержку инициализации до выполнения отложенных скриптов.

В server.py встроенный код разрешён по точному SHA-256. Также включены разрешения для двух дополнительных адресов отправки, присутствующих в текущей конфигурации этого пикселя. Google Tag Manager и существующий Lead после сохранения формы сохранены.

## Что подтверждено

- В браузере на тестовой версии пиксель инициализируется один раз.
- Отправляется один PageView; Meta возвращает HTTP 200.
- Основной дополнительный канал отправки возвращает HTTP 200.
- Google Tag Manager загружается, ошибок блокировки Content Security Policy нет.
- Проверки обработчика Lead после успешной заявки проходят.

Причина ошибки конкретного инструмента настройки в вашем кабинете не подтверждена. Перенос кода в head — изменение для совместимости со стандартным размещением, а не гарантия исчезновения ошибки или зелёной галочки. Это нужно проверить в кабинете после установки. Реальный Lead уже был подтверждён вашим скриншотом тестирования событий.

Изменения подготовлены локально, на работающем сайте их ещё нужно установить.
