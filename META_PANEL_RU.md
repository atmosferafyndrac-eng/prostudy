# Исправление загрузки панели настройки событий Meta

Для https://prostudy.com.ua/, пикселя 2295810454598491 и версии репозитория 557ad7e.

## Что исправлено

Панель настройки событий загружается самим пикселем отдельным скриптом с адреса `https://www.facebook.com/signals/iwl.js`. В текущей политике сайта этот адрес отсутствует в script-src, поэтому браузер запрещает загрузку панели. Разрешение адреса www.facebook.com в connect-src или frame-src не разрешает выполнение скриптов.

В server.py добавлено разрешение именно для этого файла в script-src. Другие файлы сайта в этот архив не включены.

## Установка

1. Загрузите `server.py` из архива в корень репозитория https://github.com/atmosferafyndrac-eng/prostudy и сохраните изменения.
2. Обновите и перезапустите приложение на хостинге. Для Docker Compose в папке проекта на сервере:

   ```sh
   git pull
   docker compose up -d --build
   ```

При ручной установке замените server.py в папке проекта на сервере и перезапустите приложение.

3. Перезагрузите вкладку сайта через Ctrl+F5.
4. В Meta заново запустите инструмент настройки событий. Если он показывает старое соединение, нажмите «Отсоединить» в окне настройки, затем снова укажите https://prostudy.com.ua/ и нажмите «Добавить события». Речь идёт о подключении инструмента к вкладке сайта, а не об удалении пикселя.
5. Перейдите во вкладку сайта и проверьте появление панели Meta. При появлении дополнительных ошибок нужен скрин именно этой панели или сообщений браузера. Повторно создавать Lead на кнопке не требуется.

## Что проверено

В актуальном коде Meta fbevents.js установлено, что загрузчик IWL использует адрес www.facebook.com/signals/iwl.js. Затем в браузере на тестовой копии вызван штатный загрузчик Meta с заведомо недействительным диагностическим токеном, без использования данных аккаунта. При исходной политике получена блокировка CSP; с исправленной политикой запрос больше не блокируется CSP. Ответ с недействительным токеном не является проверкой авторизованной панели.

Фактическое открытие панели в вашем аккаунте и изменение зелёной галочки пока не подтверждены. Обновление устраняет воспроизведённую блокировку её загрузчика.

Официальный исходный скрипт Meta: https://connect.facebook.net/en_US/fbevents.js
