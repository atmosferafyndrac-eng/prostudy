# Исправление запросов панели Meta

Для https://prostudy.com.ua/ и пикселя 2295810454598491. Основа: версия репозитория 12d55de.

На скриншоте консоли панель Meta уже загрузилась, но запросы к api.facebook.com/signals/event-rules-list/pixel/ и graph.facebook.com/v18.0/ заблокированы директивой connect-src. В server.py добавлены разрешения для https://api.facebook.com и https://graph.facebook.com. Ранее добавленное разрешение загрузчика панели сохранено.

## Установка

1. Распакуйте архив и загрузите `server.py` в корень репозитория https://github.com/atmosferafyndrac-eng/prostudy. Сохраните изменения.
2. Обновите и перезапустите сайт на хостинге. Для Docker Compose в папке проекта на сервере:

   ```sh
   git pull
   docker compose up -d --build
   ```

При ручной установке замените server.py в папке проекта на сервере и перезапустите приложение.

3. Перезагрузите вкладку сайта через Ctrl+F5 и заново откройте настройку событий из Meta. Если окно ошибки осталось, нажмите «Повторить попытку».
4. Если появилась рабочая панель настройки, завершите работу через кнопку «Завершить настройку» внутри панели. Не создавайте повторное событие Lead на кнопке: оно уже вызывается после сохранения заявки.

## Проверка

В браузере на тестовой копии воспроизведена блокировка обоих адресов до изменения и подтверждено отсутствие блокировки CSP после изменения. Использовались анонимные запросы без данных аккаунта, cookie и токенов Meta. Это проверяет разрешения сайта; успешный ответ на авторизованные запросы панели проверяется после установки в вашем браузере.

Обновление исправляет конкретные ошибки безопасности с предоставленного скриншота. Появление зелёной галочки мастера отдельно не проверено. На работающем сайте обновление ещё нужно установить.
