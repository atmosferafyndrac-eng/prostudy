# Событие Lead после успешной отправки формы

Для https://prostudy.com.ua/ и Meta Pixel 2295810454598491.

## Установка

1. Распакуйте `prostudy-lead-update.zip`.
2. Загрузите `app.js` и `index.html` в корень репозитория https://github.com/atmosferafyndrac-eng/prostudy через Add file → Upload files и сохраните изменения.
3. Обновите сайт на хостинге. При использовании Docker Compose выполните в папке проекта на сервере:

   ```sh
   git pull
   docker compose up -d --build
   ```

При ручной установке замените `app.js` и `index.html` в папке `static/` на сервере. Обновление `index.html` меняет адрес подключения скрипта на `app.js?v=9`, чтобы браузеры загрузили новую версию.

## Как работает

После сохранения заявки сервер возвращает успешный ответ с положительным числовым номером заявки. Только после этого сайт вызывает стандартное событие Meta:

```js
fbq('track', 'Lead');
```

При ошибках заполнения, сервера, сети и при отклонении антиспам-полем Lead не вызывается. Телефон, имя и содержимое заявки в параметры этого вызова не добавляются. Если пиксель недоступен, форма продолжает работать.

## Проверка

После публикации откройте тестирование событий для пикселя 2295810454598491 в Meta Events Manager. Посетите сайт без блокировщика рекламы и отправьте корректно заполненную форму. Когда появится подтверждение с номером заявки, проверьте появление Lead в Meta. При открытии страницы по-прежнему отправляется PageView.

Локально проверены успешная отправка, ошибки проверки данных/API/сети, ответ антиспам-поля и работа формы при недоступном пикселе. На работающий сайт обновление ещё нужно установить. Основа: версия репозитория 5e91190.
